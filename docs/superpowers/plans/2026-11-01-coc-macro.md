# CoC Macro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desktop app (Python, tkinter) that loops "search village → attack if gold and elixir are high enough → replay recorded deployment → surrender past a damage % → go back" on Clash of Clans in Google Play Games PC, with the game window in the background.

**Architecture:** `winctl` talks to the Win32 window (capture by `PrintWindow`, input by `PostMessage`, both verified in the spike). `bot.py` is a state machine that only talks to a `Game` protocol, so it is tested with a scripted fake; `game.py` is the real implementation (templates + OCR + player). GUI and hotkeys are a thin layer on top.

**Tech Stack:** Python 3.12, tkinter, ctypes, numpy, opencv-python, Pillow, pynput, pytest. OCR backend chosen in Task 4.

**Spec:** `docs/superpowers/specs/2026-11-01-coc-macro-design.md`

## Global Constraints

- Windows 11 only; Python; tkinter UI (single window, no extra frameworks).
- Game window: process `crosvm`, title starts with `Clash of Clans`. Client area measured 1296×729 (offset 9,38 inside a 1315×776 window).
- Capture: `PrintWindow(hwnd, dc, 2)`. Input: `PostMessage` `WM_LBUTTONDOWN` (0x0201, wParam 1) / `WM_LBUTTONUP` (0x0202, wParam 0) / `WM_MOUSEMOVE` (0x0200) to the top-level hwnd, lParam = client coords.
- All stored coordinates are **relative 0–1** to the client area. Aspect ratio change → warn and ask to recalibrate.
- Defaults: gold_min = 500000, elixir_min = 500000, surrender_pct = 50. Emergency stop **F8** (global), end deployment recording **F9**.
- Never click on an unrecognised screen: every wait has a timeout; on timeout the bot stops and logs.
- First launch shows the Supercell ToS / ban-risk warning once.
- No mutation of the game, no memory reads, no injection.
- Git: Gitflow, branch `feature/coc-macro` from `develop`, Conventional Commits, atomic commits that each pass `pytest`. No `Co-Authored-By` / `Claude-Session` trailers.

## Review Focus

1. Game window missing or closed mid-run → bot stops with a clear log line, no exception trace to the user. (Task 2, Task 6)
2. Window minimized → capture fails detectably, bot refuses to start / stops, tells the user. (Task 2)
3. OCR returns nothing or garbage (loading screen, counters still animating) → never attack on `None`; re-read, and `Siguiente` (Next) only after a valid read below threshold. (Task 4, Task 6)
4. Numbers in different formats (`3 482 103` with spaces, `335.532`, `1545`) parse to the right integer. (Task 4)
5. F8 pressed mid-deployment or mid-wait stops within ~1 s and leaves no stuck mouse button (always send an `up` after a `down`). (Task 5, Task 8)
