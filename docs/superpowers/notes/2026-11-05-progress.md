## Findings that changed the design
- Camera is not fixed: zoom out (6 wheel turns at 0.5,0.45) before selecting a wall.
- Cannot-pay price is salmon (~255,110,110), not pure red.
- `+10` label turns red when < 10 walls of the level remain: use `+1`.
- Mejorar on walls opens a Cancelar/Vale dialog ("Mejorar muros ... Oro xN"). `confirm_upgrade` = that Vale; only it is ever clicked.
- The Construir menu has FOUR tabs and REMEMBERS the last one: builders (0/7), researchers (0/2), forge / hero equipment (NEVER touched, the user forbade it, no button for it exists), pets (0/1). Filters: builders = Permanente + Coste min; researchers = only Coste min (no Permanente there); pets = no filter, the bot takes the first row under the "Asignado" header (my call: cheapest cannot be read reliably).
- Every tab opens the SAME window on a row press: "Mejorar tu X al nivel N?" with a green Confirmar (resource) on the right and a grey Confirmar (hammer item) on the left. Only the green one is pressed (fixed position), only if the price is not red.
- `upgrade_busy` (replaces `upgrade_cheapest_permanent`) reads the three counters inside the menu, then runs each tab that has a free slot. Dry run live (everything busy): opens, reads 0/0/0, closes.
- Bot gate for busy mode: free builder/researcher in the village, storages full, or every 5th attack (pets).
- Not tested (need a free builder): the success path of both routines, the wall Vale dialog, any real upgrade.
